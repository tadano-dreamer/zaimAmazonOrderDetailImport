## 4. 消すと決めたときの手順メモ

- ①②: docs とコメントをダミー・伏せ字・「実データで件数と合計の一致を確認」程度の文へ。テストの名前は「商品A」などへ(期待値は変えない)。
- ③: `scripts/make_dummy_data.js` のカード番号を架空の番号に → ダミーを再生成 → Python で正解CSVを再生成(ファイル名も)
  → `web/js/core.test.js`・`tests/e2e.cjs`・`scripts/verify_*.js` → スクショ撮り直し → `core.js` と Python の既定カードを外す。
  アプリは端末が覚えたカードと期間内の利用件数で選ぶので影響なし。Python 版は `--card` の指定が必要になる。
- 消したあと: PC で `data/` と照合し直し、注文ID・カード下4桁・ブランド名が追跡ファイルに0件であることを確かめる。
  `node --test web/js/core.test.js`・`scripts/verify_dummy.js`・`scripts/verify_parity_fuzz.js`・e2e を流す。
